# poker_bot — «Покерный клуб»

Telegram Mini App для закрытых клубов, домашних cash-игр и турниров.
Пользователь открывает приложение кнопкой в боте или через меню «Открыть клуб».
Создание клуба, приглашения, участники, игры, история и рейтинги находятся в Mini App.
Бот не предлагает текстовые диалоги управления.

Текущие требования: [сценарий продукта](docs/product.md).
GitHub и последующее размещение: [Git и Amvera](docs/git-amvera.md).

## Запуск для Telegram

В `.env` задаются `BOT_TOKEN`, `DATABASE_URL`, публичный HTTPS-адрес `MINI_APP_URL`
и `BOT_USERNAME` (имя бота без `@` для ссылок приглашения).
Секреты и базы не входят в Git. Для личного теста используйте отдельную базу,
например `sqlite:///data/telegram-test.db`.

Запустите два процесса из корня проекта:

```powershell
python -m alembic upgrade head
python -m uvicorn app:app --host 127.0.0.1 --port 8767
```

Во втором терминале:

```powershell
python -m poker_bot.polling
```

HTTP-сервер должен быть доступен по `MINI_APP_URL` через HTTPS-хостинг или туннель.
После изменения адреса перезапустите бота: он обновляет кнопку меню через Bot API.
При открытии `/start` бот показывает одну кнопку запуска приложения; старые кнопки
текстового интерфейса также ведут в приложение. Приглашение проверяется сервером
после входа через Telegram. Публиковать `poker_bot.demo` через туннель нельзя:
деморежим предназначен только для локального просмотра.

Для работы с этого компьютера нужны запущенные процессы и доступ к Telegram API.
Текущее `amvera.yml` запускает только polling: для постоянного размещения ещё нужно
подготовить запуск HTTP-сервера, HTTPS и постоянный диск, секреты и согласовать тариф.

## Что работает

- Закрытые клубы, приглашения, гости и роли с серверной проверкой прав.
- Проверка подписи и срока действия Telegram initData.
- Cash: входы, докупки, кэшауты, сверка и исправления с журналом.
- Турниры: итоговые места, исправления и защита от устаревших форм.
- История, личная статистика и раздельные cash- и турнирные рейтинги.
- Mini App на мобильном и настольном экране, светлая и тёмная темы.
- Миграции Alembic и отдельные демоданные.

## Локальная разработка в Windows / VS Code

Эти команды нужны только разработчику, не для ежедневной работы бота.

1. Установить Python 3.13 с python.org, включив **Add Python to PATH**.
2. В VS Code открыть папку проекта и терминал PowerShell:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m uvicorn app:app --reload
```

Не заменять существующий `.env`, если в нём уже есть настройки.
В `.env` для разработки остаётся `DATABASE_URL=sqlite:///data/poker.db`.
Для проверки `/health` токен Telegram не нужен. Endpoint webhook требует
`WEBHOOK_SECRET`, а реальная обработка Telegram — также `BOT_TOKEN`.
Миграции выполняются отдельной командой, а не при каждом HTTP-запросе.

В этой рабочей среде для проверок установлен переносной Python в `.tools/python`.
Он не входит в Git и облачный пакет. Обычному пользователю устанавливать его
для работы опубликованного бота не понадобится.

## Принятые решения

- Для выбранной Amvera: SQLite на `/data/poker.db`, один экземпляр приложения.
  Поддержка PostgreSQL и webhook остаётся дополнительной возможностью.
- Серверное состояние диалогов в базе, без зависимости от памяти функции.
- Гости идентифицируются внутренним ID, пользователи Telegram — числовым ID.
- Валюты: RUB, UZS, USD, EUR, KZT (2 знака), JPY (0 знаков); суммы — целые
  минимальные единицы. После создания игры валюта клуба блокируется.
- Транзакции SQLite используют `BEGIN IMMEDIATE`; PostgreSQL — общую advisory
  lock для последовательной обработки изменений небольшого клуба.
- Стиль интерфейса: спокойные полупрозрачные поверхности в духе Apple,
  единая композиция и светлая/тёмная темы. Стеклянные кнопки — внутри виджетов;
  обычные inline-кнопки отображает Telegram.
- Резервное копирование облачной базы и восстановление проверяются в день 4.
