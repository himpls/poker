# Работа с проектом

- Основной сценарий: ссылка на бота → вход через Telegram → закрытый клуб →
  cash-игра или турнир → итоги от владельца/организатора → история и рейтинг.
- Денежную прибыль cash и турнирные места хранить и показывать отдельно.
- Опираться на существующую реализацию. Правки схемы — новой миграцией Alembic;
  уже применённые миграции не переписывать.
- Права проверять на сервере. Данные Telegram Mini App проверять по подписи initData.
- Вести Git: отдельный коммит для законченного изменения после проверок,
  перед коммитом проверять diff и состав файлов. Не переписывать историю.
- Не добавлять токены, `.env`, базы, кэши и `.tools` в коммиты.
- Проверки: `python -m pytest -q`, для интерфейса — браузерная проверка.
- Рабочие базы не использовать для тестов. Демо запускается отдельно.
- Публикация в Amvera — через Git после настройки HTTPS, постоянного диска,
  секретов и согласования тарифа. Push в Amvera запускает размещение.
- Текущие требования: `docs/product.md`; Git и размещение: `docs/git-amvera.md`.
